## Selected teaching explanation

### Start with the audience and niche

A business profile should make its subject clear. Before choosing a username, writing a biography, or planning posts, identify the audience and the reason they would find the account useful.

### Connect the profile elements

The username, profile image, biography, and visual style should help the same audience recognise the business. A clear profile provides context for the content that follows.

### Choose a format for the message

The original deck introduced images, infographics, carousels, short clips, and Reels. A useful learning task is to explain why a particular message suits a particular format, rather than selecting a format without a purpose.

### Treat research as an input

Branded accounts, relevant searches, and competitor content can provide ideas for investigation. Learners should explain how a choice relates to their audience and evaluate the result.

## New portfolio practice task

**Scenario:** create an Instagram profile plan for a fictional adult training provider.

**Learning outcome:** produce a coherent profile and three content ideas that serve a defined learner need.

1. Identify one learner segment and the skill it wants to develop.
2. Propose a username and explain why it fits the subject.
3. Draft a biography that states who the training helps and the next step.
4. Describe the logo and colour choices and how they support consistency.
5. Plan three posts using different formats from the original lesson.
6. For each post, state its audience need, message, and call to action.
7. Explain how you would assess whether the content was useful.

**Submission:** a profile mockup and a three-post content plan. This is a new portfolio activity, not a historical student assignment or evidence of student performance.

## Feedback rubric

| Area | Assessment question |
| --- | --- |
| Audience | Is the intended learner specific and understandable? |
| Profile | Do the name, biography, and visual choices communicate the same offer? |
| Content | Does each idea answer an audience need? |
| Format | Is there a clear reason for the selected format? |
| Next step | Is the call to action relevant and easy to understand? |
| Reflection | Can the learner explain what they would measure or improve? |
